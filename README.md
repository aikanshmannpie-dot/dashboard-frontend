## Dashboard2-Frontend Documentation 

---

Few simple steps to run Dashboard2-Frontend on your local machine :
 
1. Clone the main repository https://acqalice9@bitbucket.org/acquirelydev/dashboard2frontend.git . Please run below command on your favorite terminal.

	**`git clone https://acqalice9@bitbucket.org/acquirelydev/dashboard2frontend.git`**

2. Install required packages in the above repository inside **Code** folder.

	**`npm install`**
	
3.  Run Website on your local machine with command line
	
	**`npm run start`**
	
Website start  on Your localhost on port 3000 and url be like *`localhost:3000`*
